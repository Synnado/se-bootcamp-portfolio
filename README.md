## 📚 What I Learned

### Day 01: Digital Foundation
- เรียนรู้พื้นฐานของเทคโนโลยีดิจิทัลและระบบคอมพิวเตอร์ และ เข้าใจบทบาทของฮาร์ดแวร์ ซอฟต์แวร์ และการสื่อสารข้อมูลในยุคดิจิทัล

### Day 02: Logic & Flowgorithm Lab 1
- ศึกษาหลักการคิดเชิงตรรกะและการแก้ปัญหาอย่างเป็นขั้นตอน ฝึกออกแบบอัลกอริทึมและสร้างผังงาน Flowchart

### Day 03: Flowgorithm Lab 2–3
- ฝึกใช้งานโครงสร้างการตัดสินใจ และการทำงานแบบวนซ้ำ พัฒนาทักษะการคิดวิเคราะห์และการออกแบบขั้นตอนการทำงานของโปรแกรม

### Day 04: AI, Web Technology and Network
- เรียนรู้พื้นฐานของปัญญาประดิษฐ์ หรือที่เราเรียกว่า AI และการประยุกต์ใช้งาน ศึกษาเทคโนโลยีเว็บไซต์ การทำงานของอินเทอร์เน็ต

### Day 05: GitHub and Developer Tools
- เรียนรู้การจัดการเวอร์ชันของโค้ดด้วย Git และ GitHub
